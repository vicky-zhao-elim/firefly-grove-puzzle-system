# Firefly Grove Puzzle System
L2 Digital Technologies AS91896

This is a demo of a possible puzzle system for Firefly Grove, a cosy nature puzzle game.

The camera can pan over the world using arrow keys (up, down, left, right), and you can drag cards onto dark slots in the world. The aim is to figure out the pattern of the plants on the stage to complete the puzzle. Once completed, a message will pop up showing that it is correct.
